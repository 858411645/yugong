# Backend Development Guidelines

> Best practices for backend development in this project.

---

## Overview

This project has **no backend**. It is a pure client-side web game (HTML + CSS + Vanilla JS) served as static files. All "backend" guidelines reference the current state and describe conventions to follow if a backend is later added.
